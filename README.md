# JEJAK KEMERDEKAAN: DIPLOMASI DAN REVOLUSI FISIK (1945–1949)
### Platform Edukasi Sejarah Digital & Arsip Interaktif Kemerdekaan Indonesia

Website ini merupakan media pembelajaran sejarah digital yang memadukan kedalaman riset akademis, verifikasi arsip primer, kurasi foto dokumentasi autentik, dan pengalaman pengguna bertaraf museum digital modern (*Historical Editorial — Digital History Archive*).

## 📚 2. Struktur Konten & Kedalaman Riset Sejarah

Materi sejarah disusun berdasarkan standar riset kritis dan kajian sumber terpercaya (Arsip Nasional RI, Nationaal Archief Belanda, Dekrit DK PBB, George McTurnan Kahin, A.H. Nasution, M.C. Ricklefs, Mestika Zed):

1. **Pengantar Geopolitik 1945:**
   - Konteks pasca-kapitulasi Jepang, pendaratan Sekutu (AFNEI), dan ambisi rekolonisasi NICA.
   - Hakikat dwitunggal strategi: *Mengapa diplomasi dan revolusi fisik bekerja bagaikan dua bilah mata gunting*.
2. **Linimasa Interaktif Diplomasi (8 Peristiwa Rinci):**
   - **Perjanjian Linggarjati (1946–1947):** Pengakuan de facto atas Jawa, Madura, Sumatera; Uni Indonesia-Belanda; perbedaan penafsiran kedaulatan.
   - **Agresi Militer Belanda I (Juli 1947):** *Operatie Product*, penyerbuan sentra perkebunan & minyak, internasionalisasi sengketa ke DK PBB oleh India & Australia.
   - **Komisi Tiga Negara / KTN (Agustus 1947):** Peran Australia (Kirby), Belgia (van Zeeland), dan AS (Graham) sebagai mediator PBB.
   - **Perjanjian Renville (Januari 1948):** Garis Status Quo Van Mook, Long March Hijrah Divisi Siliwangi ke Yogyakarta, jatuhnya Kabinet Amir Sjarifuddin.
   - **Agresi Militer Belanda II (Desember 1948):** *Operatie Kraai*, serbuan Maguwo, penangkapan Soekarno-Hatta, dimulainya Perang Gerilya Semesta Jenderal Soedirman.
   - **Pemerintahan Darurat RI / PDRI (1948–1949):** Penyelamatan konstitusi oleh Mr. Syafruddin Prawiranegara dari rimba Bidar Alam via pemancar radio morse AURI.
   - **Perundingan Roem-Royen (Mei 1949):** Naskah pernyataan bersama di Hotel des Indes, penarikan serdadu Belanda, dan peristiwa *Jogja Kembali* (29 Juni 1949).
   - **Konferensi Meja Bundar / KMB (1949):** Sidang Ridderzaal Den Haag, Mohammad Hatta, penyerahan kedaulatan de jure 27 Desember 1949, dan Mosi Integral Natsir kembali ke NKRI (17 Agustus 1950).
3. **Studi Mendalam Revolusi Fisik: Bandung Lautan Api (23–24 Maret 1946):**
   - Latar belakang perebutan senjata Jepang (ACW Kiaracondong, Andir, Gedung Sate).
   - Kedatangan Sekutu Brigade 37 MacDonald dan provokasi NICA.
   - Rangkaian ultimatum Sekutu (pembagian jalur rel KA dan ancaman bom udara RAF).
   - Musyawarah darurat Regentsweg pimpinan Kolonel A.H. Nasution.
   - Malam pembumihangusan terkoordinasi dan evakuasi akbar 200.000 rakyat ke pegunungan selatan.
   - Aksi martir Mohammad Toha & Mohammad Ramdan meledakkan gudang mesiu Sekutu di Dayeuhkolot.
   - Analisis dampak militer (*Pyrrhic victory* bagi Sekutu) dan lahirnya doktrin Sishankamrata TNI.
   - Historiografi lagu *Halo-Halo Bandung* karya Ismail Marzuki (fakta sejarah vs mitos populer).
   - Arsitektur simbolis Monumen Bandung Lautan Api di Lapangan Tegallega karya pematung Sunaryo (1984).
4. **Matriks Komparasi Diplomasi vs Revolusi Fisik:**
   - Tabel perbandingan komprehensif 7 dimensi analitis.
5. **Biografi Tokoh Bangsa:**
   - 9 Tokoh Kunci: Mohammad Hatta, Sutan Sjahrir, Mohammad Roem, Syafruddin Prawiranegara, A.H. Nasution, Mohammad Toha, Mohammad Ramdan, Amir Sjarifuddin, Haji Agus Salim.
6. **Kuis Sejarah Interaktif:**
   - 12 Pertanyaan pilihan ganda akademis dengan pembahasan jawaban seketika dan skor evaluasi.
7. **Monograf Lengkap Terpisah:**
   - Tersedia naskah monograf akademik setebal 93 KB pada berkas `PENELITIAN_SEJARAH_LENGKAP.md`.

## 🚀 4. Cara Menjalankan & Menguji Proyek Secara Lokal

Website ini dibangun menggunakan teknologi murni web modern (**Semantic HTML5, CSS3 Kustom, dan Vanilla JavaScript ES6**). Tidak memerlukan `npm install`, tidak memerlukan proses *compilation*, serta bebas dari kerentanan *dependency*.

### Opsi A: Membuka Langsung di Peramban
Cukup klik ganda berkas `index.html` pada File Explorer, atau klik kanan lalu pilih **Open with Google Chrome / Microsoft Edge / Firefox**. Seluruh fitur timeline, galeri, modal lightbox, pencarian cepat, dan kuis akan berfungsi secara langsung.

### Opsi B: Menggunakan Local Web Server (Direkomendasikan)
Jika Anda memiliki VS Code, gunakan ekstensi **Live Server**:
1. Buka folder `Project Sejarah` di VS Code.
2. Klik kanan pada `index.html` -> pilih **Open with Live Server**.
3. Akses melalui peramban di `http://localhost:5500`.

## ☁️ 5. Panduan Lengkap Deployment ke Vercel

Proyek ini telah dikonfigurasi secara sempurna untuk hosting di **Vercel** melalui berkas `vercel.json`.

### Cara 1: Deployment Otomatis via GitHub (Paling Direkomendasikan)

1. **Inisialisasi & Unggah ke GitHub:**
   - Buat repositori baru di akun GitHub Anda (misal: `jejak-kemerdekaan-1945-1949`).
   - Unggah seluruh berkas dari folder `Project Sejarah` ke repositori tersebut:
     ```bash
     git init
     git add .
     git commit -m "Inisialisasi website Jejak Kemerdekaan 1945-1949"
     git branch -M main
     git remote add origin https://github.com/USERNAME/jejak-kemerdekaan-1945-1949.git
     git push -u origin main
     ```
2. **Hubungkan Repositori ke Vercel:**
   - Masuk ke dasbor [vercel.com](https://vercel.com).
   - Klik tombol **"Add New..."** lalu pilih **"Project"**.
   - Cari dan pilih repositori `jejak-kemerdekaan-1945-1949` dari akun GitHub Anda, lalu klik **"Import"**.
3. **Konfigurasi Project Settings:**
   - **Framework Preset:** Pilih `Other` (Static HTML/CSS/JS).
   - **Root Directory:** `./` (biarkan default).
   - **Build and Output Settings:** Kosongkan (tidak perlu build command).
4. **Deploy:**
   - Klik tombol **"Deploy"**.
   - Dalam hitungan detik (5–10 detik), situs Anda akan aktif dengan domain global gratis (contoh: `https://jejak-kemerdekaan-1945-1949.vercel.app`).
   - Setiap kali Anda melakukan `git push` pembaruan konten, Vercel akan secara otomatis memperbarui website secara instan!

---

### Cara 2: Deployment Langsung via Vercel CLI

Jika Anda memiliki Vercel CLI di komputer Anda:
1. Buka terminal di folder proyek:
   ```powershell
   cd "c:\AntiGravity\Project Sejarah"
   ```
2. Jalankan perintah:
   ```powershell
   vercel
   ```
3. Ikuti instruksi di terminal (tekan Enter untuk menerima default pengaturan).
4. Untuk deployment ke environment produksi:
   ```powershell
   vercel --prod
   ```
